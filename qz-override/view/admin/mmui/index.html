默认开启。统计脚本加载自 static.sermc.net，使用 Matomo 且禁用 Cookie。仅用于了解 MMUI ECS 页面使用情况：页面访问与链接点击、当前域名、NAT 标记、虚拟化类型、操作系统、MMUI 版本/代号、当前主题、通过 ipapi 解析出的地区；不会写入系统密码、面板密码、用户名、实例名称、具体 IP 原文或端口映射内容。
